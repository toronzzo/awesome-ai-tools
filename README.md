# Awesome AI Tools

A curated list of tools and libraries for building, training, serving, evaluating, and applying AI systems.

## Preyas picks

These are the tools that matter most for the Preyas roadmap:

- [llama.cpp](https://github.com/ggml-org/llama.cpp) - run open models efficiently on local hardware.
- [LiteLLM](https://github.com/BerriAI/litellm) - route requests across model providers through one API.
- [Unsloth](https://github.com/unslothai/unsloth) - fine-tune open models efficiently with low memory use.
- [Sentence-Transformers](https://github.com/huggingface/sentence-transformers) - generate embeddings for semantic memory search.
- [Chroma](https://github.com/chroma-core/chroma) - store and search embeddings for a simple local memory layer.
- [Promptfoo](https://github.com/promptfoo/promptfoo) - test prompts and compare models to prevent regressions.

## Fine-tuning and training

- [Unsloth](https://github.com/unslothai/unsloth) - fast, low-memory fine-tuning.
- [Axolotl](https://github.com/axolotl-ai-cloud/axolotl) - configurable fine-tuning pipelines.
- [LLaMA-Factory](https://github.com/hiyouga/LLaMA-Factory) - fine-tuning framework with a web UI.
- [TRL](https://github.com/huggingface/trl) - reinforcement learning and preference tuning.
- [PEFT](https://github.com/huggingface/peft) - parameter-efficient methods such as LoRA.

## Core model libraries

- [Transformers](https://github.com/huggingface/transformers) - standard library for loading and running open models.

## Running models locally

- [llama.cpp](https://github.com/ggml-org/llama.cpp) - efficient local model inference on ordinary hardware.
- [Ollama](https://github.com/ollama/ollama) - easy local model setup and serving.
- [vLLM](https://github.com/vllm-project/vllm) - high-throughput model serving.

## Retrieval, RAG, and app building

- [LlamaIndex](https://github.com/run-llama/llama_index) - data connectors and retrieval pipelines.
- [LangChain](https://github.com/langchain-ai/langchain) - chains, tools, and AI application building blocks.
- [Haystack](https://github.com/deepset-ai/haystack) - production-oriented search and RAG.
- [DSPy](https://github.com/stanfordlp/dspy) - prompt and pipeline optimization.

## Vector databases

- [Chroma](https://github.com/chroma-core/chroma) - simple, embeddable vector store.
- [Qdrant](https://github.com/qdrant/qdrant) - fast vector search with filtering.

## Embeddings

- [Sentence-Transformers](https://github.com/huggingface/sentence-transformers) - embedding models for semantic search.

## Data labeling and dataset tools

- [Argilla](https://github.com/argilla-io/argilla) - human feedback and dataset curation.
- [Label Studio](https://github.com/HumanSignal/label-studio) - text, image, and audio labeling.
- [Datasets](https://github.com/huggingface/datasets) - loading and processing datasets at scale.

## Evaluation and monitoring

- [Ragas](https://github.com/explodinggradients/ragas) - evaluate RAG quality.
- [Promptfoo](https://github.com/promptfoo/promptfoo) - test prompts and model behavior against custom cases.
- [MLflow](https://github.com/mlflow/mlflow) - track experiments and model versions.

## Chat interfaces and gateways

- [Open WebUI](https://github.com/open-webui/open-webui) - self-hosted chat interface for local and API models.
- [LiteLLM](https://github.com/BerriAI/litellm) - unified gateway across model providers.
